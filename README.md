## מה זה

אפליקציה בעברית למעקב אחרי תיק מניות אמריקאיות. מוסיפים אחזקה — סימול, כמות
ומחיר קנייה — והמחירים מתעדכנים לבד. רואים את שווי התיק, הרווח או ההפסד,
השינוי היומי וההתפלגות בין האחזקות.

לכל מניה אפשר להגדיר **גבול עליון ותחתון**, ולקבל התראה ברגע שהמחיר חוצה
אותם.

האפליקציה עובדת בדפדפן, ואפשר להוסיף אותה למסך הבית בטלפון כך שתיראה ותתנהג
כמו אפליקציה רגילה — אייקון משלה, מסך מלא, ועבודה גם בלי אינטרנט.

## התקנה על הטלפון

**אייפון (Safari):** פותחים את הלינק ← כפתור השיתוף ← "הוספה למסך הבית".

**אנדרואיד (Chrome):** פותחים את הלינק ← האפליקציה מציעה התקנה, או דרך
תפריט שלוש הנקודות ← "התקנת אפליקציה".

## התראות — מה עובד ומה לא

ההתראות נשלחות **כל עוד האפליקציה פתוחה או רצה ברקע**. כדי לקבל התראה
כשהאפליקציה סגורה לגמרי צריך שרת שישלח אותה, ולפרויקט הזה אין כזה עדיין.

באייפון, התראות עובדות רק אחרי הוספה למסך הבית (iOS 16.4 ומעלה). זו מגבלה
של אפל: אתר שפתוח בספארי לא יכול לבקש הרשאת התראות.

## מאיפה מגיעים המחירים

ספק הנתונים לא מאפשר פנייה ישירה מהדפדפן, ולכן:

1. GitHub Actions מריץ כל 5 דקות, בשעות המסחר בארה"ב, את
   `scripts/fetch-prices.mjs`.
2. הסקריפט מושך מחירים לכל הסימולים שב-`scripts/universe.json`.
3. התוצאה נדחפת כקובץ בודד לענף `data`.
4. האפליקציה קוראת אותו משם.

במעקב 284 מניות ותעודות סל.

המחירים יכולים להיות מאוחרים ב-5 עד 15 דקות — האפליקציה תמיד מציגה מתי
עודכנו לאחרונה. **להוספת מניה למעקב:** מוסיפים את הסימול ל-`universe.json`.

## פרטיות וגיבוי

אין שרת ואין חשבון. כל הנתונים נשמרים בדפדפן של המשתמש בלבד ולא נשלחים
לשום מקום. כל אחד שפותח את הלינק מקבל תיק ריק משלו.

מכיוון שהנתונים יושבים בדפדפן בלבד, ניקוי היסטוריית הגלישה ימחק אותם.
לכן יש באפליקציה **שמירה לקובץ ושחזור ממנו** — זו גם הדרך להעביר תיק
למכשיר אחר.

## פיתוח

```bash
npm install
npm run dev
```

הבנייה לייצור:

```bash
npm run build
```

להורדת הפרויקט למחשב:

```bash
git clone https://github.com/talfarage3331/menayot.git ~/Desktop/menayot
```

## פריסה

כל דחיפה ל-`main` מפעילה את `.github/workflows/deploy.yml`, שבונה ומפרסם
ל-GitHub Pages. לוקח בערך דקה.

## מבנה

| נתיב | תפקיד |
| --- | --- |
| `scripts/` | רשימת הסימולים והסקריפט שמושך מחירים |
| `src/lib/` | חישובים, פורמט והתראות — קוד טהור בלי מצב |
| `src/hooks/` | ניהול המצב, משיכת מחירים ושמירה ל-localStorage |
| `src/components/` | רכיבי תצוגה |
| `CLAUDE.md` | מדריך הפרויקט — נקרא על ידי Claude בכל שיחה חדשה |
