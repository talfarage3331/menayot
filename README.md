## מה זה

אפליקציה בעברית למעקב אחרי תיק המניות שלך. מוסיפים אחזקה — סימול, כמות,
מחיר קנייה ומחיר נוכחי — ורואים מיד את שווי התיק, הרווח או ההפסד, וההתפלגות
בין האחזקות.

האפליקציה עובדת בדפדפן, ואפשר להוסיף אותה למסך הבית בטלפון כך שתיראה ותתנהג
כמו אפליקציה רגילה — אייקון משלה, מסך מלא, ועבודה גם בלי אינטרנט.

## התקנה על הטלפון

**אייפון (Safari):** פותחים את הלינק ← כפתור השיתוף ← "הוספה למסך הבית".

**אנדרואיד (Chrome):** פותחים את הלינק ← האפליקציה מציעה התקנה, או דרך
תפריט שלוש הנקודות ← "התקנת אפליקציה".

## פרטיות

אין שרת ואין חשבון. כל הנתונים נשמרים בדפדפן של המשתמש בלבד ולא נשלחים
לשום מקום. כל אחד שפותח את הלינק מקבל תיק ריק משלו.

מכיוון שהנתונים יושבים בדפדפן, ניקוי היסטוריית הדפדפן ימחק אותם.

## פיתוח

```bash
npm install
npm run dev
```

הבנייה לייצור:

```bash
npm run build
```

להורדת הפרויקט למחשב:

```bash
git clone https://github.com/talfarage3331/menayot.git ~/Desktop/menayot
```

## פריסה

כל דחיפה ל-`main` מפעילה את `.github/workflows/deploy.yml`, שבונה ומפרסם
ל-GitHub Pages. לוקח בערך דקה.
